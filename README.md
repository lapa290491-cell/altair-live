# Альтаир Live / Altair Live

Сибирский информационно-развлекательный медиапортал нового поколения.

**Не просто что случилось. Что это меняет, для кого и что будет дальше.**

География: Иркутск, Улан-Удэ, Красноярск и вся Сибирь.

## Статус

- Публичный адаптивный сайт: **реализован** (демо-режим)
- Редакционная панель: **интерфейс готов** (демо)
- Source Radar + Второй вопрос: **архитектура и UI подготовлены**
- Supabase / Auth / RLS: **миграции подготовлены**, требуется подключение
- Деплой: готов к Vercel

## Локальный запуск (для разработчика)

```bash
npm ci
cp .env.example .env.local
# заполните NEXT_PUBLIC_SITE_URL и при необходимости Supabase
npm run dev
```

Откройте http://localhost:3000

## Демонстрационный режим

По умолчанию `DEMO_MODE=true`. Все учебные материалы помечены **«Демонстрация»** и не должны индексироваться в продакшене.

## Деплой с телефона (Vercel + GitHub)

1. Откройте GitHub в браузере телефона → репозиторий `altair-live`.
2. Перейдите на [vercel.com](https://vercel.com) → Import Project → выберите этот репозиторий.
3. В Environment Variables добавьте переменные из `.env.example` (секреты только в Vercel).
4. Deploy.
5. Для Supabase: создайте проект на [supabase.com](https://supabase.com), скопируйте URL и ключи, выполните миграции из `supabase/migrations/` через SQL Editor.
6. Bootstrap владельца: создайте пользователя в Supabase Auth, затем вручную установите роль `owner` в таблице `profiles`.

## Структура

- `app/` — маршруты Next.js App Router
- `components/` — UI
- `lib/demo-data.ts` — учебные материалы
- `supabase/migrations/` — схема БД
- `app/admin/` — редакционная панель

## Следующие шаги владельца

1. Подключить Supabase и выполнить миграции.
2. Создать первого owner.
3. Настроить домен.
4. Добавить реальные источники в Source Radar.
5. (Опционально) подключить AI-провайдер.

## Безопасность

- Секреты никогда не коммитятся.
- RLS будет включён после подключения Supabase.
- Админ-маршруты требуют авторизации в production.
