# Безопасность

- Никаких секретов в репозитории.
- `.env.example` без значений.
- Админ-маршруты в production должны быть защищены Supabase Auth + RLS.
- Demo-материалы всегда помечены и исключены из индексации.
- Cron endpoints требуют CRON_SECRET.
- XSS: rich-text будет санитизироваться при подключении редактора.
